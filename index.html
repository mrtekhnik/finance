Калькулятор валют

⇅

Впишите сумму в любое из двух полей — второе пересчитается само. Не привязано к вашим счетам.

Калькулятор депозита

По состоянию на 2026 год ставка налога на проценты по депозитам в Украине — 23% (18% НДФЛ + 5% военный сбор). Можно изменить, если ставка поменяется. Не привязано к вашим счетам — просто отдельный калькулятор.

Калькулятор цели

Взносы вносятся в конце каждого месяца, проценты начисляются ежемесячно с капитализацией. Налог берётся из настройки калькулятора депозита. Без доходности расчёт просто делит оставшуюся сумму на месяцы.

Настройки рисков

Границы, при которых на «Главной» появляется предупреждение. Можно менять под себя.

Банки

Стрелками меняйте порядок — он используется в сортировке «Свой порядок банков» на экране «Счета».

Категории операций

Нажмите ✕, чтобы убрать категорию. Старые операции сохранят своё название.

Синхронизация через GitHub

Связывает телефон и ПК через ваш приватный репозиторий. Отправка только по кнопке ⟳ вверху экрана.

Резервная копия

Сохраните данные в файл, чтобы не потерять их при очистке данных браузера или смене телефона.

Экспорт в Excel / CSV

Список всех счетов в виде таблицы — можно открыть в Excel или Google Таблицах. Это не резервная копия для восстановления, а просто просмотровый файл.

Защита паролем

Запрашивать пароль при входе

Это простой экран входа — защита от случайного взгляда, а не настоящее шифрование. Забыли пароль — восстановить его нельзя, только очистить данные сайта в Chrome (это сотрёт всё; поэтому держите свежую резервную копию).
